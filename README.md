# AI Talent Finder — Version 1.0

A beginner-friendly IT recruitment sourcing assistant prototype.

## Features
- Paste a job description and detect technology skills from a starter dictionary.
- Upload candidate profiles as CSV.
- Compare candidate skills and experience against a JD using a transparent rule-based score.
- Generate Boolean search strings for sourcing platforms.
- Download a shortlist and a candidate CSV template.

## Requirements
- Python 3.10 or newer
- Internet connection for the first installation only

## Run on Windows
1. Install Python from https://www.python.org/downloads/ and tick **Add Python to PATH**.
2. Extract this ZIP file.
3. Open the extracted `ai_talent_finder_v1` folder.
4. Click the folder address bar, type `cmd`, and press Enter.
5. Run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

6. A browser tab should open with the AI Talent Finder dashboard. If it does not, copy the Local URL shown in Command Prompt (usually http://localhost:8501) into your browser.

## First test
- Select **Use sample candidates for a demo**.
- Paste a JD such as: `Java Full Stack Developer 5+ years Java Spring Boot Microservices Angular REST API AWS`.
- Set minimum experience to 5.
- Click **Match candidates to this JD**.

## Important limitations
This is Version 1.0, a rule-based prototype. The displayed match score is not generated by a language model and is not a hiring recommendation. The skill dictionary is limited and should be expanded. It does not scrape LinkedIn, Naukri, Indeed or Hirist, and it does not infer whether a candidate is actively looking for work.

Use candidate information only when you have an appropriate lawful basis and permission. Use official APIs or platform-approved integrations for future enrichment. Do not upload unnecessary sensitive personal information.
